## 二、HTML 预渲染与 JS 交互规则
1. 所有 100 个问题的答案在编译阶段完全渲染为标准 HTML `<p>`, `<ul>`, `<code>` 标签。
2. JS 仅负责 UI 的 `<details>` / `aria-expanded` 手风琴折叠展开，确保搜索引擎与 AI 爬虫抓取完整的静态文本。
3. 每个答案字数控制在 150~350 字之间，严禁产生“A是B”式的无价值薄内容（Thin Content）。
